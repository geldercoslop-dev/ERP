🔥 SE ALGO DER ERRADO
═════════════════════

❌ "DATABASE_URL não configurado"
→ Editar .env.production, adicionar: 
  DATABASE_URL=mysql://user:pass@localhost:3306/db

❌ "Database não respondeu"
→ Verificar:
  • MySQL está rodando? (mysql -u root -p)
  • HOST/PORT/USER/SENHA corretos?
  • Firewall bloqueando acesso?

❌ "Redis não respondeu"  
→ Verificar:
  • Redis está rodando? (redis-cli ping)
  • HOST/PORT corretos?
  • Docker rodando se usar container?

❌ "Servidor não inicia"
→ Verificar:
  • Porta 3001 está livre? (netstat -an | findstr :3001)
  • dist/ foi gerado? (pnpm build)
  • Erros no console? (ver logs)

❌ "TypeScript errors"
→ Rodar: pnpm run typecheck
→ Corrigir erros listados
→ Revalidar: pnpm run validate:final
