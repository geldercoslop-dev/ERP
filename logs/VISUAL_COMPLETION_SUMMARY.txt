┌─ TESTES IMPLEMENTADOS ────────────────────────────────────────────────────┐
│                                                                             │
│  ╔════════════════════════════════════════════════════════════════════╗   │
│  ║ TEST 1: Rollback On Error (Transações ACID)                      ║   │
│  ╚════════════════════════════════════════════════════════════════════╝   │
│                                                                             │
│  Simula:   BEGIN TRANSACTION                                               │
│            INSERT pedido ✅                                               │
│            UPDATE estoque ✅                                              │
│            ERROR no financeiro ❌                                         │
│            ROLLBACK?                                                       │
│                                                                             │
│  Valida:   Estado ANTES == Estado DEPOIS (zero mudanças)                  │
│            Nenhuma mudança parcial fica salva                              │
│            Isolamento de transação funciona                               │
│                                                                             │
│  ───────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  ╔════════════════════════════════════════════════════════════════════╗   │
│  ║ TEST 2: Concurrent Stock Orders (Race Conditions)                ║   │
│  ╚════════════════════════════════════════════════════════════════════╝   │
│                                                                             │
│  Simula:   Produto: estoque = 10                                           │
│            Ordem 1: -7 unidades (paralelo)                                │
│            Ordem 2: -7 unidades (paralelo)                                │
│                                                                             │
│  Valida:   Apenas 1 ordem sucede (estoque insuficiente)                   │
│            Estoque NUNCA fica negativo                                    │
│            Locking funciona (SELECT ... FOR UPDATE)                       │
│                                                                             │
│  Resultado: Estoque final = 3 (10 - 7)                                    │
│                                                                             │
│  ───────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  ╔════════════════════════════════════════════════════════════════════╗   │
│  ║ TEST 3: Idempotency (Deduplicação)                               ║   │
│  ╚════════════════════════════════════════════════════════════════════╝   │
│                                                                             │
│  Simula:   Enviar MESMO pedido 10x em paralelo:                           │
│            - 1ª requisição: cria pedido                                   │
│            - 2-10ª requisições: usam resultado da 1ª                      │
│                                                                             │
│  Valida:   Apenas 1 novo pedido no banco                                  │
│            Resto das requisições reutilizam resultado                     │
│            Sem duplicatas mesmo em caso de retry                          │
│                                                                             │
│  Resultado: Pedidos ANTES + 1 == Pedidos DEPOIS                           │
│                                                                             │
│  ───────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  ╔════════════════════════════════════════════════════════════════════╗   │
│  ║ TEST 4: Data Integrity (Relacionamentos)                         ║   │
│  ╚════════════════════════════════════════════════════════════════════╝   │
│                                                                             │
│  Valida:   ❌ Nenhum pedido órfão (sem itens de pedido)                  │
│            ❌ Nenhum item referenciando produto inválido                 │
│            ❌ Nenhuma conta receber sem pedido                           │
│            ❌ Nenhum total descasado (pedido.total != SUM(itens))        │
│                                                                             │
│  Resultado: Integridade referencial mantida = ✅ PASSED                   │
