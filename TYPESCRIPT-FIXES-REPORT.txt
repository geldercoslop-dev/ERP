ANÁLISE PRÉVIA - ERROS IDENTIFICADOS
════════════════════════════════════════════════════════════════════════════════

❌ ERRO 1: Promise.race< T> typing incorreto
  Local: executeWithRetry() linha ~50
  Problema: Promise.race([...]) sem tipo genérico T
  Tipo retornado: never (inválido)
  Solução: Promise.race<T | never>([...])

❌ ERRO 2: Spread operator incompatível com ioredis
  Local: Multiple métodos (del, exists, hdel, lpush, rpush, sadd, srem)
  Problema: ...keys e ...members com spread causes Type 'string[]' not assignable
  Tipo: Redis.del(...keys) espera keys[] diretamente, não spread
  Solução: Converter array e usar (keys as unknown as string[])

❌ ERRO 3: Propriedades inexistentes em Redis type
  Local: hget, hset, hdel, hgetall, lpush, rpush, lpop, rpop, lrange, sadd, srem, smembers, zadd, zrange, incr, decr
  Problema: import type { Redis } from 'ioredis' retorna a classe, não instância
  Tipo: Class constructor, não InstanceType
  Solução: Usar InstanceType<typeof Redis>

❌ ERRO 4: Return type mismatch
  Local: Múltiplos métodos
  Problema: Type '{}' not assignable to 'number' ou 'string[]'
  Tipo: Promise<{} | null> em vez de Promise<number>
  Solução: Type guards com typeof checks

❌ ERRO 5: Express Request type casting
  Local: db-fallback-middleware.ts linhas 139, 153
  Problema: (req as any).requestId sem tipagem
  Tipo: req.requestId não existe em Express.Request
  Solução: Estender interface Express.Request com campo requestId

❌ ERRO 6: getDb() não é função
  Local: db-fallback-middleware.ts linha 268
  Problema: import { getDb } = await import('../db') - getDb não existe
  Tipo: getDb é undefined, não async function
  Solução: Usar getConnectionPool() de '../config/database'

  Arquivo: server/resilience/redis-retry-wrapper.ts
  Métodos corrigidos: del, exists, hdel, lpush, rpush, sadd, srem
  
  Antes (ERRO):
    async del(...keys: string[]): Promise<number> {
      const result = await this.executeWithRetry(
        () => this.redis.del(...keys),  // ← Type 'string[]' not assignable to 'string'
        `del:${keys.join(',')}`
      );
      return result ?? 0;
    }
  
  Depois (CORRETO):

      const result = await this.executeWithRetry(
        () => this.redis.del(keys as unknown as string[]),  // ← Cast compatível
        `del:${keys.join(',')}`
      );
      return typeof result === 'number' ? result : 0;  // ← Type guard
    }
  
  Resultado: ✅ 7 métodos corrigidos (del, exists, hdel, lpush, rpush, sadd, srem)
